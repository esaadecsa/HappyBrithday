# HappyBirthday — Versi Interaktif Lengkap

Struktur:
- index.html
- style.css
- script.js
- img/hbd1.png       <- salin dari project lama
- music/monokrom.mp3 <- salin dari project lama

index.html memanggil:
<link rel="stylesheet" href="style.css">
<script src="script.js"></script>

Alur interaktif:
1. Buka surat
2. Ucapan ulang tahun
3. Ada satu lagi / Gift
4. Pilihan: YA atau TIDAK
5. TIDAK -> halaman "Yaudah kalau ga mau, wle 😝"
6. Ditawari lagi
7. YA -> halaman Happy Birthday + confetti

Semua ID tombol dan nama screen di index.html sudah disinkronkan dengan script.js.
style.css berisi seluruh desain untuk screen baru gift/nope.
