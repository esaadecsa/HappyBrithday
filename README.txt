# HappyBirthday — versi baru

Upload `index.html`, `style.css`, dan `script.js` ke root repository yang sama.
Folder `img` dan `music` dari repo lama tetap dipakai.

## Yang perlu diubah
Buka `script.js`, lalu edit:

name: "kamu",
birthday: "2026-10-22T00:00:00+07:00",

Tanggal `birthday` disimpan untuk pengembangan berikutnya. Versi desain ini langsung membuka surprise tanpa countdown agar tidak macet ketika tanggal sudah lewat.

Pastikan file berikut tetap ada:
- img/hbd1.png
- music/monokrom.mp3
